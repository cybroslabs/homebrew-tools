## ouroctl apply basemap

Upload an export of the vector tile server as the basemap

### Synopsis

Upload an export of the vector tile server (an uncompressed tar) so the deployment serves its
map without reaching the vector tile server. The platform checks the export once it is complete;
when the checks pass, it becomes the basemap in use and the previous upload is deleted. When they
fail, the basemap in use stays as it is.

A broken connection is retried from the bytes the platform already holds. An upload that stops
can be continued with --resume and the upload id it reports, for 48 hours after its last block.
Needs the basemap manage permission, and is refused where the deployment takes its basemap from
the vector tile server.

```
ouroctl apply basemap [flags]
```

### Examples

```
  # Upload an export and wait for its checks
  ouroctl apply basemap --file cz-sk.tar

  # Continue an upload that stopped
  ouroctl apply basemap --file cz-sk.tar --resume 019ab6f2-3c4d-7e8f-9a0b-1c2d3e4f5a6b

  # Return once the file is sent; follow the checks with 'ouroctl get basemap'
  ouroctl apply basemap --file cz-sk.tar --no-wait
```

### Options

  -h, --help[=true|false]      help for basemap

      --resume string          Continue the upload with this id instead of starting a new one
