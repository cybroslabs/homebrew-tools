## ouroctl apply environment

Restore the device configuration of an environment from YAML

### Synopsis

Applies a file written by 'get environment': every object the target lacks is created and
every object that differs is updated, matched by name. Nothing is ever deleted, and applying
the same file again changes nothing. There is no --replace: existing objects are always updated.

Before anything is written, the zones, modem pools, communication buses and drivers the file
needs are checked; if any is missing, nothing is applied. An object that fails is reported and
the rest continue; objects that refer to it fail with the reason.

Secured values are not in the file. Objects that already exist keep theirs; objects created from
the file are created without them, unless the secrets file written by
'get environment --include-secrets' is given with --secrets. Device keys are applied separately
with 'apply secrets'.

```
ouroctl apply environment [flags]
```

### Examples

```
  # Show what would change
  ouroctl apply environment --file environment.yaml --dry-run

  # Apply it
  ouroctl apply environment --file environment.yaml

  # Apply only the devices, four at a time
  ouroctl apply environment --file environment.yaml --only devices --parallel 4
```

### Options

```

  -f, --file string      Path to the environment file to apply
  -h, --help             help for environment
      --only string      Comma-separated kinds to apply: fieldDescriptors, registers, variables, templates, cus, devices, groups (default: all)
      --parallel int     Concurrent writes for communication units and devices (1-16) (default 1)
      --secrets string   Secrets file written by 'get environment --include-secrets'
```
