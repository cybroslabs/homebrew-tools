## ouroctl apply locations

Apply object locations from JSON file

### Synopsis

Apply the WGS84 locations of devices, communication units and business objects from a JSON file.
Objects are named, never given by id. An object that already has a location is left as it is
unless --replace is given; a replace is refused when the location changed since it was read.

Each entry takes objectType (DEVICE, COMMUNICATION_UNIT or BUSINESS_OBJECT), name, latitude and
longitude, and optionally accuracyM, sourceRef, observedAt (RFC 3339), locked, and originalCrs
with originalX and originalY to record the coordinates the location was given in at its origin.
Converting those to WGS84 is the file's job. Writing a locked location, or changing a lock,
needs the location lock permission.

```
ouroctl apply locations [flags]
```

### Examples

```
  # Set the locations of objects that have none
  ouroctl apply locations --file locations.json

  # Also update the locations objects already have
  ouroctl apply locations --file locations.json --replace

  # Show what would be written without writing it
  ouroctl apply locations --file locations.json --replace --dry-run

  # locations.json
  [
    {
      "objectType": "DEVICE",
      "name": "AM550 12345678",
      "latitude": 50.0755,
      "longitude": 14.4378,
      "accuracyM": 3,
      "sourceRef": "GIS-4711",
      "originalCrs": "EPSG:5514",
      "originalX": -742512.3,
      "originalY": -1043256.8
    }
  ]
```
