## ouroctl get environment

Export the device configuration of the environment to YAML

### Synopsis

Exports the device configuration of the environment to one YAML file that 'apply environment'
restores into the same or another environment: user-defined field descriptors, registers,
variables, device configuration templates, communication units, devices with their links,
and device groups with their static members.

Objects refer to each other by name. Zones, modem pools, communication buses and drivers are
listed as prerequisites: they are not exported and must exist in the target.

Secured values (passwords and other attributes marked secured) are never written to the file.
With --include-secrets DIR they are written to DIR/env.secrets.yaml instead, and the device keys
to DIR/crypto-<DRIVER>.json in the format 'apply secrets' reads. Both are created readable by
the owner only, and existing files are not replaced without --force.

```
ouroctl get environment [flags]
```

### Examples

```
  # Export everything to environment.yaml
  ouroctl get environment

  # Also export the secured values and the device keys
  ouroctl get environment --include-secrets ./secrets

  # Export registers, variables and templates only
  ouroctl get environment --file config.yaml --only registers,variables,templates
```

### Options

      --only string              Comma-separated kinds to export: fieldDescriptors, registers, variables, templates, cus, devices, groups (default: all)
