## ouroctl get locations

Retrieve object locations

### Synopsis

Retrieves the locations of devices, communication units and business objects as json in the
format 'apply locations' takes, with objects named rather than given by id. An object whose
name another object of its type also carries is left out with a warning.

```
ouroctl get locations [flags]
```

### Examples

```
  # Every location, to locations.json
  ouroctl get locations

  # Only the devices' locations
  ouroctl get locations --object-type DEVICE --file device-locations.json
```

### Options

```
  -h, --help[=true|false]     help for locations
  -o, --object-type strings   Export only these object types: DEVICE, COMMUNICATION_UNIT, BUSINESS_OBJECT (repeatable or comma-separated; default all)
```
